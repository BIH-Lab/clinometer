Clinometer

스마트폰을 나침반 겸 경사계로 사용해 암반면의 주향(走向)과 경사(傾斜)를 측정합니다. 측정을 시작하면 나침반·기울기 센서 사용 권한을 요청합니다.

자편각이란?

나침반 바늘이 가리키는 자북(빨간 선)과 지도가 기준으로 삼는 진북(점선)은 위치마다 몇 도씩 차이가 납니다. 이 차이를 자편각이라 하며, 보정하지 않으면 나침반으로 읽은 방위가 실제 지도의 방위와 어긋나게 됩니다. 위 그림은 예시이며 실제 각도는 지역마다 다릅니다.

이 페이지가 HTTPS로 접속되지 않아 센서 권한을 사용할 수 없습니다. GitHub Pages로 배포된 https:// 주소로 접속해주세요.
센서 권한이 거부되었습니다. 브라우저 설정에서 동작 및 방향 센서 권한을 허용한 뒤 새로고침해주세요.
주향과 경사란?

주향(strike)은 기울어진 암반면과 수평면이 만나는 선의 방향입니다. 방향이 없는 "선"이므로 북(N)을 기준으로 한 각도로 N60°E처럼 표기합니다 (동서 방향이면 E-W, 남북 방향이면 N-S).

경사(dip)는 주향과 90도를 이루는 방향(가장 급하게 내려가는 방향)으로 암반면이 수평면에서 얼마나 기울었는지의 각도(0~90°)입니다. 30°SE는 남동쪽으로 30도 기울었다는 뜻입니다. 측정할 때는 먼저 평평한 상태로 90도 돌려 방향을 맞춘 뒤 기울여서 각도를 읽으세요 (많이 기울면 나침반 방위가 부정확해질 수 있어 방향은 평평했을 때 값을 자동으로 사용합니다). 각도를 읽는 동안에는 앞뒤 기울기·방위(회전) 확인 막대가 둘 다 초록색을 유지하도록 폰을 고정해주세요.

지질도에서는 긴 선으로 주향을, 짧은 눈금으로 경사가 내려가는 방향을, 숫자로 경사각을 표시합니다. 완전히 수평이면 ⊕, 완전히 수직이면 내려가는 쪽이 없으므로 눈금을 긴 선 양쪽에 대칭으로 그립니다.
