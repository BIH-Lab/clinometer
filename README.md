# 클리노미터 (웹 주향/경사 측정기)

스마트폰 브라우저에서 나침반·기울기 센서를 이용해 암반면의 주향(strike)과 경사(dip)를 측정하는 웹 앱입니다. 빌드 과정 없이 순수 HTML/CSS/JS로 작성되어 GitHub Pages에 그대로 올리면 바로 동작합니다.

## 사용 방법

1. 필요하면 "자편각 보정" 값을 입력하거나 "📍 GPS로 계산"을 누른 뒤, "측정 시작"을 누르고 센서 권한을 허용합니다. (iOS는 반드시 이 버튼을 눌러야 권한 창이 뜹니다.)
2. **① 주향 측정**: 스마트폰을 암반면에 대고 좌우 수평계가 초록색이 될 때까지 기울인 뒤 "주향 기록"을 누릅니다. 이때 화면에 표시된 방위가 주향입니다.
3. **② 경사 측정**: 스마트폰을 90도 돌려 최대 경사 방향(내려가는 방향)으로 맞춘 뒤 기울여서 "경사 기록"을 누릅니다. 좌우 기울기 값이 경사 각도가 됩니다.
4. **③ 결과 확인**: 주향/경사와 지질도 기호를 확인합니다. "새로 측정"을 누르면 처음부터 다시 잴 수 있습니다.

이 앱은 측정값을 따로 저장하지 않는 1회성 측정 도구입니다 (기록이 필요하면 화면을 캡처하거나 직접 받아 적어야 합니다).

## 자편각(magnetic declination) 보정

스마트폰 나침반은 자북(magnetic north)을 가리키지만, 지질도의 주향/경사는 진북(true north) 기준입니다. 시작 화면의 "📍 GPS로 계산" 버튼을 누르면 위치 권한을 요청한 뒤 현재 GPS 좌표와 World Magnetic Model(WMM 2025-2030, `src/declination.js`에 계수 내장 — 인터넷 연결 없이도 계산됨)로 자편각을 자동 계산해 입력칸을 채웁니다. 필요하면 직접 값을 고쳐 써도 됩니다. 이후 모든 방위·주향·경사방향 표시에 이 값이 자동으로 반영됩니다. 입력값은 저장되지 않고 새로고침하면 초기화됩니다.

## 배포 (GitHub Pages)

1. 이 폴더를 GitHub 저장소에 push합니다. (`index.html`이 저장소 루트에 있어야 함)
2. 저장소 **Settings → Pages → Source**: "Deploy from a branch" → `main` 브랜치, `/ (root)` 선택.
3. 몇 분 뒤 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속 가능합니다.
4. **반드시 https:// 주소로 접속해야 합니다.** 센서 권한 API(특히 iOS)는 HTTPS(또는 localhost)가 아니면 동작하지 않습니다.

## 알려진 제한사항 (실기기 테스트 필요)

- iOS Safari와 Android Chrome은 나침반 센서를 서로 다른 방식으로 노출하며, 이 코드는 두 방식을 모두 처리하지만 **실제 기기에서 방위 값이 맞는지 반드시 확인**해야 합니다.
- 경사가 90도에 가까운(수직) 암반면에서는 방향 센서 특성상 오차가 커질 수 있습니다.
- 자성 광물이 포함된 암석이나 금속 근처에서는 나침반 오차가 커질 수 있습니다. 정확도가 낮으면(iOS) 경고 배너가 표시됩니다. Android는 브라우저가 정확도 정보를 제공하지 않아 배너가 뜨지 않습니다.
- 화면 자동 회전을 켜둔 상태에서 기기를 가로/세로로 바꾸면 값이 어긋날 수 있으니, 세로 모드로 고정해서 사용하는 것을 권장합니다.
- 일부 기기/브라우저(특히 구형 Android WebView)는 절대 방위(나침반) 센서 자체를 지원하지 않습니다. 이 경우 "나침반 미지원" 경고가 뜨며, 다른 기기나 최신 Chrome 등으로 시도해야 합니다.
- 앱 아이콘은 SVG 하나만 포함되어 있습니다. iOS 홈 화면 아이콘은 SVG를 지원하지 않아 스크린샷으로 대체될 수 있으니, 필요하면 `icons/` 폴더에 PNG 아이콘을 추가하세요.
