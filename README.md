# 클리노미터 (웹 주향/경사 측정기)

스마트폰 브라우저에서 나침반·기울기 센서를 이용해 암반면의 주향(strike)과 경사(dip)를 측정하는 웹 앱입니다. 앱 설치 없이 링크만 열면 바로 사용할 수 있습니다.

**바로 사용하기: https://bih-lab.github.io/clinometer/**

스마트폰(아이폰 Safari, 안드로이드 Chrome 권장)에서 위 링크를 열어 사용하세요. 홈 화면에 추가하면 아이콘이 생겨 일반 앱처럼 열 수 있고, 한 번 열어두면 오프라인(신호 없는 현장)에서도 계속 사용할 수 있습니다.

## 사용 방법

1. (선택) 시작 화면에서 "자편각 보정" 값을 입력하거나 "GPS로 계산"을 눌러 자동으로 채웁니다.
2. "측정 시작"을 누르고 센서 권한을 허용합니다. (iOS는 이 버튼을 눌러야만 권한 창이 뜹니다.)
3. **① 주향 측정**: 스마트폰을 암반면에 대고 좌우 수평계가 초록색이 될 때까지 기울인 뒤 "주향 기록"을 누릅니다. 그때 화면에 표시된 방위가 주향입니다.
4. **② 경사 측정**: 스마트폰을 90도 돌려 최대 경사 방향(내려가는 방향)으로 맞춘 뒤 기울여서 "경사 기록"을 누릅니다. 좌우 기울기 값이 경사 각도가 됩니다.
5. **③ 결과 확인**: 주향/경사 값과 지질도 기호를 확인합니다. "새로 측정"을 누르면 처음부터 다시 잴 수 있습니다.

이 앱은 값을 서버나 파일에 저장하지 않는 **1회성 측정 도구**입니다. 여러 지점을 기록해야 한다면 매번 화면을 캡처하거나 직접 받아 적어주세요.

## 자편각(자북 vs 진북) 보정이 필요한 이유

스마트폰 나침반은 자북(magnetic north)을 가리키지만, 지질도의 주향/경사는 진북(true north) 기준으로 표기합니다. 두 방향 사이의 오차(편각)를 보정하지 않으면 값이 실제 지도와 어긋날 수 있습니다. "GPS로 계산" 버튼을 누르면 현재 위치 기준으로 편각을 자동 계산해 채워주며(인터넷 연결 없이도 동작), 값이 마음에 안 들면 직접 고쳐도 됩니다. 이 값은 저장되지 않고 새로고침하면 초기화됩니다.

## 사용 시 참고사항

- **기종에 따라 나침반이 안 될 수 있음**: 일부 오래된 기기/브라우저는 나침반(방위) 센서 자체를 지원하지 않습니다. "나침반 미지원" 경고가 뜨면 다른 기기나 최신 브라우저(Chrome 등)로 시도해보세요.
- **경사 90도 근처(수직에 가까운 암반)** 에서는 센서 특성상 오차가 커질 수 있습니다.
- **자성 광물이 포함된 암석이나 금속 근처**에서는 나침반 오차가 커질 수 있습니다. 정확도가 낮으면(iOS 기기) 화면에 보정 안내가 뜹니다.
- 화면 자동 회전을 켜둔 채 기기를 가로/세로로 바꾸면 값이 어긋날 수 있으니, **세로 모드 고정**을 권장합니다.
- 반드시 **https://** 주소로 접속해야 합니다. 센서 권한(특히 iOS)은 HTTPS가 아니면 아예 동작하지 않습니다.
